A game recommendation web service based on user preferences.

**My Role**
- Backend sub-leader
- Game data collection from IGDB API

- Game like/unlike API development
- TOP100 game filtering by genre

- Genre filtering, search, fuzzy search, pagination

- User-based `is_liked` response
- `like_count` response
- Game like / unlike API
- DB-based game data storage to reduce external API dependency
